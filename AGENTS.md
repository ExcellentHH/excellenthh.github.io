# Project Instructions

This repository is Haohua Duan's academic homepage.

Before making changes:
1. Read `HOMEPAGE_SPEC.md` completely.
2. Preserve the existing AcadHomepage/Jekyll architecture.
3. Do not replace the theme or introduce a new frontend framework.
4. Do not invent academic achievements, publications, awards, links, or biographical information.
5. If information or an asset is missing, use a clear TODO placeholder.
6. Keep the website primarily in English.
7. Optimize for both desktop and mobile.
8. Do not enable Google Scholar crawler or analytics unless explicitly requested.
9. Do not publish or merge to `main` unless explicitly requested.
10. Keep changes focused and minimal.

After each major change:
- verify that the Jekyll site can build;
- report modified files;
- report unresolved TODOs.
